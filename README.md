Title :
SmartBudget — Personal Budget Management System
Intro :
SmartBudget Manager est une application qui permet de gérer ses revenus, de
suivre ses dépenses, de planifier son budget et de mieux contrôler ses finances
personnelles, et il contien 3 chose principales : Dashboard, Transactions et
Categories
À propos de l&#39;audience :
1. Qui utilisera le fichier ?
Tout le monde — n&#39;importe qui — peut organiser ses
dépenses.
2. Quel est leur niveau sur Excel ?
Ils ont des connaissances de base sur Excel.
3. Quelles tâches doivent-ils effectuer ?
Enregistrer les revenus, les dépenses et gérer le budget.
4. Quels termes peuvent être difficiles ?
Les termes comme revenus, dépenses, solde et budget.
5. Quels problèmes peuvent-ils rencontrer ?
Des erreurs de saisie ou la suppression des formules.
6. Comment vont-ils lire la documentation ?
Ils vont la lire rapidement pour trouver les informations
importantes.

Calcul du solde : connaître l&#39;argent restant.
Gestion des catégories : classer les dépenses (alimentation,
transport, logement…).
Tableau de bord : afficher un résumé de la situation financière.
Contrôle du budget : détecter les dépassements de dépenses.
Suivi mensuel : consulter les revenus et les dépenses par mois.
